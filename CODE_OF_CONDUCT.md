# Code of Conduct

## Our Pledge

We pledge to make participation in our project a welcoming and respectful experience for everyone.

## Our Standards

All contributors should:

- Be respectful and kind.

- Welcome different opinions.

- Give constructive feedback.

- Avoid harassment and discrimination.

- Respect other contributors.

## Enforcement Responsibilities

Project maintainers are responsible for enforcing this Code of Conduct and addressing unacceptable behavior.

## Scope

This Code of Conduct applies to all project spaces, including GitHub discussions, issues, and pull requests.

## Enforcement

Violations of this Code of Conduct may be reported privately to the project maintainers through an appropriate contact channel.

## Enforcement Guidelines

Maintainers will follow these guidelines:

1. Correction: A private warning for inappropriate behavior.

2. Warning: A formal warning for repeated violations.

3. Temporary Ban: Temporary restriction from project participation.

4. Permanent Ban: Permanent removal for serious violations.
